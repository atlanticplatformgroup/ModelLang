# ModelLang 0.11 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.11 consists of the complete [ModelLang 0.10 language](../0.10/LANGUAGE.md) plus the [0.11 operation transport semantics](./TRANSPORT.md).

Version 0.11 does not change source grammar or canonical IR shape. It retains canonical IR version 9 and defines a versioned operation manifest derived exclusively from that IR.

Where 0.11 differs from an earlier version, the 0.11 rule takes precedence. [Conformance](./CONFORMANCE.md) is cumulative.
