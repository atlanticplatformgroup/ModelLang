# ModelLang 0.35 unstable boundaries

The following remain outside the stable read contract: arbitrary caller-selected fields or directions, compound authored sort keys, nullable sort fields, offset or page-number pagination, caller-controlled page size, cursor signing or encryption, frozen cross-request snapshots, collection or reverse traversal, inferred joins, runtime-selected projection paths or depth, aliases, computed fields, inline anonymous shapes, conditional key omission, redaction reason payloads, per-field authorization traces, runtime field selection, collection-member disclosure, nested-row-scoped conditions, aggregates, grouping, full-text search, caching, field-level capability negotiation, MCP-specific result contracts, and generic CRUD.

Conditional disclosure is a closed compile-time projection rule, not a dynamic selection or authorization surface. A redactable key is always present and uses `null` both for source null and redaction, so consumers cannot distinguish those states from the transport value alone. Rules belong to one query and are not inherited by other queries that reuse the projection. Nested conditions evaluate in the root query scope; every redactable ancestor needs its own rule.

Authored sort profiles remain a closed compile-time allowlist. Profile selection grants no authority and does not add or disclose a projection field. A cursor remains opaque continuation state bound to the exact caller, filters, and selected profile; each page is a new authenticated, policy-filtered, and disclosure-evaluated read under its own database statement snapshot.
