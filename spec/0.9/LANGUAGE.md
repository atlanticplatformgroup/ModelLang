# ModelLang 0.9 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.9 consists of the complete [ModelLang 0.8 language](../0.8/LANGUAGE.md) plus the [0.9 workflow semantics](./WORKFLOWS.md).

Where 0.9 differs from an earlier version, the 0.9 rule takes precedence. The [grammar](./GRAMMAR.ebnf) extends 0.8, and [conformance](./CONFORMANCE.md) is cumulative.
