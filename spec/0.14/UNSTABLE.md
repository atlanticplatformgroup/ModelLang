# ModelLang 0.14 unstable workflow-application boundaries

The following remain undefined or host-owned:

- authorization-based visibility, permission preflight, capability discovery, guard explanation, and disabled-state policy;
- stale-state refresh, optimistic concurrency, retries, idempotency, conflict reconciliation, offline transitions, and optimistic UI;
- button placement, confirmation, destructive styling, notifications, progress, undo, compensation, and history displays;
- parallel, hierarchical, cross-entity, wildcard, timed, asynchronous, event-driven, and compensating workflow forms;
- transition grouping, priorities, default actions, keyboard shortcuts, icons, localization, product copy, and analytics;
- entity loading, routing, page composition, relationship option sources, editable result forms, and generic CRUD;
- server-side workflow capability endpoints or transport representations beyond declared action execution;
- independently deployed manifest compatibility negotiation and remote manifest loading;
- alternate transports, alternate enforcement backends, generated framework packages, AI/MCP consumers, and package publication.
