# ModelLang 0.27 — Normative Language

Status: normative specification for the 0.27 reference compiler.

ModelLang 0.27 consists of the complete [ModelLang 0.26 language](../0.26/LANGUAGE.md) plus the [private terminal-failure observation contract](./FAILURE_OBSERVATION.md). It adds no source-language declaration or public runtime operation.

Version 0.27 retains canonical IR18, event manifest v5, engineering semantic manifest v10, semantic diff v11, operation manifest v4, capability manifest v3, UI manifest v4, decision plan v2, event envelope v2, and stable HTTP routes. The generator profile advances independently for the private operational projection.

All locked identity, authorization, applicability, workflow, reliable-command, transactional-event, reliable-consumer, event-chain, failure/recovery, migration, privilege, and fail-closed semantics from earlier versions remain normative. Where 0.27 differs, this version takes precedence.
