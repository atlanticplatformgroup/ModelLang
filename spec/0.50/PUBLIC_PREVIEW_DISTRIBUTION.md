# ModelLang 0.50 public preview distribution contract

ModelLang 0.50 retains the complete [0.49 public preview distribution contract](../0.49/PUBLIC_PREVIEW_DISTRIBUTION.md), with package/compiler version 0.50.0 and canonical IR2.

The packed artifact MUST contain the 0.50 schemas and compiler needed to validate and generate IR2. Clean-install proof MUST compile a multi-effect action as well as the reference applications. Historical IR1 normalization is not supplied; installed evolution commands accept only exact current IR2 inputs.
