# ModelLang 0.7 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.7 consists of the complete [ModelLang 0.6 language](../0.6/LANGUAGE.md) plus the [0.7 generated-value and immutability semantics](./GENERATED_VALUES.md).

Where 0.7 differs from an earlier version, the 0.7 rule takes precedence. The [grammar](./GRAMMAR.ebnf) extends 0.6, and [conformance](./CONFORMANCE.md) is cumulative.
