# ModelLang 0.4 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.4 consists of:

1. the complete [ModelLang 0.3 language](../0.3/LANGUAGE.md); and
2. the [0.4 enum-set semantics](./SETS.md).

Where the 0.4 documents differ from an earlier version, the 0.4 rule takes precedence.

The [grammar](./GRAMMAR.ebnf) extends the 0.3 grammar, and the [conformance requirements](./CONFORMANCE.md) are cumulative with 0.3.
