# ModelLang 0.8 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.8 consists of the complete [ModelLang 0.7 language](../0.7/LANGUAGE.md) plus the [0.8 exact-money semantics](./MONEY.md).

Where 0.8 differs from an earlier version, the 0.8 rule takes precedence. The [grammar](./GRAMMAR.ebnf) extends 0.7, and [conformance](./CONFORMANCE.md) is cumulative.
