# ModelLang 0.5 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.5 consists of the complete [ModelLang 0.4 language](../0.4/LANGUAGE.md) plus the [0.5 stable identity and rename-migration semantics](./IDENTITY_AND_MIGRATIONS.md).

Where 0.5 differs from an earlier version, the 0.5 rule takes precedence. The [grammar](./GRAMMAR.ebnf) extends 0.4, and [conformance](./CONFORMANCE.md) is cumulative.
