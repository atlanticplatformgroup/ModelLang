# ModelLang 0.10 — Normative Language

Status: reference-compiler specification. Rules listed in `UNSTABLE.md` carry no compatibility guarantee.

ModelLang 0.10 consists of the complete [ModelLang 0.9 language](../0.9/LANGUAGE.md) plus the [0.10 safe schema-evolution semantics](./SAFE_EVOLUTION.md).

Version 0.10 does not change source grammar or canonical IR shape. It deliberately retains canonical IR version 9 so a released 0.9 IR can be compared directly with a 0.10 model.

Where 0.10 differs from an earlier version, the 0.10 rule takes precedence. [Conformance](./CONFORMANCE.md) is cumulative.
