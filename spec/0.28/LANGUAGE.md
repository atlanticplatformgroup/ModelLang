# ModelLang 0.28 — Normative Language

Status: normative specification for the 0.28 reference compiler.

ModelLang 0.28 consists of the complete [ModelLang 0.27 language](../0.27/LANGUAGE.md) plus the [private terminal-failure acknowledgement contract](./FAILURE_ACKNOWLEDGEMENT.md). It adds no source-language declaration or public runtime operation.

Version 0.28 retains canonical IR18, event manifest v5, engineering semantic manifest v10, semantic diff v11, operation manifest v4, capability manifest v3, UI manifest v4, decision plan v2, event envelope v2, and stable HTTP routes. The compiler, example models, and private generator profile advance independently.

All locked identity, authorization, applicability, workflow, reliable-command, transactional-event, reliable-consumer, event-chain, failure, recovery, observation, migration, privilege, and fail-closed semantics from earlier versions remain normative. Where 0.28 differs, this version takes precedence.
