# ModelLang 0.28 unstable boundaries

The following remain outside the stable contract: public or agent acknowledgement, assignment, ownership, approval workflows, notifications, alerts, dashboards, batch acknowledgement, automated acknowledgement or recovery, payload inspection, broker introspection, reason taxonomies beyond bounded stable codes, acknowledgement retention, cross-model operations, and distributed tracing.

Acknowledgement records that an authenticated database operator saw one current PostgreSQL-local terminal cycle. It does not prove investigation, ownership, remediation, broker state, or eventual recovery. An acknowledgement, generation, observer Boolean, or audit row grants no authority.

The stable guarantee is isolated, immutable, single-cycle acknowledgement serialized with recovery and minimally reflected in private observation. It is not a queue administration system, assignment tracker, approval workflow, notification system, or general operations console.
