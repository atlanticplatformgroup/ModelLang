# Agent Plugins 1.0.0 schemas

These are pinned local copies of the official Agent Plugins 1.0.0 Working Draft [`plugin.schema.json`](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json) and [`mcp.schema.json`](https://agent-plugins.org/schemas/1.0.0/mcp.schema.json), retrieved 6 August 2026 for deterministic generated-package tests. The [normative specification](https://agent-plugins.org/specification) governs if it conflicts with a machine-readable schema.

Agent Plugins documentation identifies its contributors' documentation as CC BY 4.0. The emitted ModelLang package documents reference the canonical official schema identifiers; clients are not directed to these repository copies.
