# ModelLang 0.33 optional query filters plan

Status: implemented in the 0.33 reference compiler.

## Goal

Allow a query author to expose a nullable filter input without introducing inferred query semantics, caller-controlled SQL shape, dynamic ordering, or dynamic limits. Existing parameters remain required unless their query declaration explicitly appends `?`.

## Contract

Optionality belongs to non-caller query parameters only. Omission and explicit JSON null are equivalent. A present value retains the existing exact type contract. The model author must write the null comparison and the predicate that applies when a value is present; the compiler never inserts an `IS NULL OR ...` branch.

Generated TypeScript uses `property?: T | null`. Operation and semantic manifests use `optional: true`; OpenAPI and HTTP expose a non-required nullable property; UI filter descriptors distinguish `required` and `nullable`. Caller identity remains authenticated context and is never request input.

## Execution

IR22 propagates parameter nullability through scalar/entity values and optional-entity field access. PostgreSQL passes null directly, skips optional entity loads and money validation only for null, and wraps authorization and row predicates with `IS TRUE`. Present unknown entity IDs fail closed. Fixed source, projection, ordering, limit, and pagination semantics do not change.

Cursor input fingerprints include optional filters as JSON null or their canonical present value. Reusing a cursor across different filter state yields `ML_STALE:cursor:<query-id>` before row disclosure.

## Evolution and verification

Optionality participates in operation shape and pagination revision hashes. A change is breaking; query predicate changes remain review-sensitive and automatic migration planning does not bless them. Verification covers parser/type errors, nullable IR, scalar and entity filters, PostgreSQL lowering, exact transport schemas and validators, UI descriptors, semantic diff, deterministic goldens, live filtering, explicit-null equivalence, malformed values, and filter-bound cursor staleness.
