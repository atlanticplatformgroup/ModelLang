# ModelLang 0.42 agent task packets

## Goal

0.42 composes the existing stable action and query contracts into a bounded, authenticated task-context packet without creating a second policy system or executing actions.

## Implemented contract

- Catalog v4 describes a stable authenticated packet route and its bounds.
- Task packet v1 accepts exact action candidates and caller-selected query observations under closed generated schemas.
- The runtime evaluates actions through current applicability and executes observations through current query enforcement and validation.
- Packet results contain static action schemas, safe effect/lifecycle metadata, current applicability, and unchanged zero-age resource envelopes.
- Input values and authenticated identity are omitted; observations use opaque caller-selected bindings.
- Packets declare non-authority, independent reads, zero reusable lifetime, no-store transport, explicit partial semantic closure, and every known closure gap.
- MCP adapter v2 exposes the assembler as a read-only tool with exact schemas and embedded packet resource delivery. It does not advertise MCP Tasks.
- Unit and live PostgreSQL tests prove subject-specific applicability, preserved query evidence, absence of action execution/audit, schema validity, authentication, input omission, and no-store freshness.
