# ModelLang 0.49 public preview readiness

## Outcome

ModelLang 0.49 turns the verified reference compiler into a bounded public-preview distribution. The release artifact is a public npm package named `modellang` with the `modelc` executable, compiled compiler modules, runtime dependencies, canonical schemas, license, changelog, and user documentation.

The milestone proves the artifact rather than merely declaring package metadata: the health gate packs the exact npm tarball, rejects development-only contents, installs it into an empty consumer directory, runs the installed compiler, builds the Procurement model, and generates an Agent Plugin package.

## Contract

- npm identity: `modellang@0.49.0`;
- executable: `modelc`;
- runtime: Node.js 20 or newer;
- license: Apache-2.0;
- public package contents: `dist/src`, all schema documents, README, changelog, license, and package manifest;
- excluded contents: tests, repository scripts, generated goldens, examples, milestone plans/specifications, and local metadata;
- installation validation: clean npm consumer with no source checkout assumptions;
- release validation: tag/version equality, deterministic model regeneration, full health suite, live PostgreSQL, and npm publication from a GitHub-hosted runner;
- compatibility: exact current IR1 only and latest-preview-minor security support.

## Repository readiness

The repository adds dual-version CI for the supported Node range, a live PostgreSQL job, tag-driven npm release automation, contribution guidance, a private security-reporting policy, a release checklist, and an install-to-Agent-Plugin preview guide.

This checkout has no configured Git remote. A repository URL is therefore not fabricated in package metadata. Creating the public repository, reserving the npm name through the first publish, and configuring npm trusted publishing are explicit one-time owner operations documented in `RELEASING.md`; they are external publication state, not compiler behavior.

## Version axes

- compiler, npm package, and examples: 0.49.0;
- public package name: `modellang`;
- canonical IR: IR1;
- generator profile: `postgresql-http-ui-agent-plugin/32` unchanged;
- MCP adapter v6, catalog v7, target profile v9 and target `/9`, external Agent Plugins 1.0.0 package format, assessment/evaluation formats, and runtime envelope versions: unchanged.

## Deferred work

A hosted application service, identity-provider setup, public Procurement deployment, npm registry publication, Agent Plugin registry/archive/signing, compatible-client certification, package-support SLA, and complete SML-Agent/SML-Federation conformance remain outside 0.49. Those require external accounts, deployment choices, or new semantic/runtime contracts rather than package readiness alone.
