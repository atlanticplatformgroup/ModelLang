# ModelLang 0.40 current-state agent resources

## Goal

0.40 exposes current state to authenticated agents by reusing declared queries rather than introducing a generic entity API. The result is useful for agent context while preserving every existing read authorization and disclosure boundary.

## Implemented contract

- Agent catalog v3 adds one exact resource binding to each query tool.
- Generated OpenAPI and browser-safe clients expose stable per-query resource routes.
- The generated server authenticates, validates exact query input, rejects command metadata, runs the existing query executor, validates output, and returns resource envelope v1.
- The envelope contains current query data but not the request, authenticated identity, extension metadata, expressions, runtime internals, or private evidence.
- Freshness is explicit and conservative: point-in-time retrieval, zero reusable lifetime, revalidation before reuse, and `Cache-Control: no-store`.
- Existing cursor behavior, conditional disclosure, result bounds, authorization, and transactional read evidence are preserved.
