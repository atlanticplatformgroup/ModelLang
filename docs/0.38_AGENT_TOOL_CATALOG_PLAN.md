# ModelLang 0.38 static agent tool catalog

## Goal

0.38 adds the first agent-facing contract without widening runtime authority. `agent-tools.json` is a deterministic projection of operation manifest v11 and capability manifest v10. It is suitable as input to an MCP tool adapter, but it is not itself an MCP server or an SML-Agent implementation.

## Contract

- Catalog v1 includes every declared action and query with stable operation ID and authored name.
- Each tool carries a standalone JSON Schema 2020-12 input and output document. Objects are closed, enum values are inlined, relationship inputs and entity output references use UUIDs, exact money remains a currency/decimal-string object, nested read projections are recursively inlined, and query collection/page bounds remain explicit.
- Execution bindings name the existing authenticated `POST` route and state that runtime authorization remains required.
- Actions add the existing authenticated applicability route, fixed outcomes, safe authorization/precondition/revision rule IDs, reliability, error classes, and declared emitted-event IDs.
- Queries add read-only annotation, result cardinality and maximum item count, authored sorting/disclosure metadata, and static read-evidence metadata when declared.

## Safety boundary

The catalog is static and is not filtered for one authenticated subject. It contains no rule expressions, current state, extension contracts or implementation locations, SQL/runtime names, command receipts, event instances, audit rows, or authority grants. Applicability grants no authority, and execution reloads and enforces current identity, authorization, preconditions, transitions, invariants, and concurrency controls.

## Deferred
