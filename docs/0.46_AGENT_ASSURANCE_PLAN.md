# ModelLang 0.46 adversarial agent assurance

## Outcome

ModelLang 0.46 turns the whitepaper's SML-Agent checklist and evaluation proposal into executable assurance contracts without claiming conformance or benchmark success. Generated models receive a conservative ten-criterion assessment; the repository gains a deterministic hostile-client suite and provider-neutral scenario/replay/scoring formats.

## Threat model

An agent may forge identity, widen inputs, mix command or delegation metadata into other operation kinds, reuse a favorable preflight after context changes, replay stale resources, infer private implementation details, substitute an extension adapter, confuse executable results with resources, or interpret discovery and explanations as authority. Runtime validation and authorization must reject these attempts independently of agent behavior.

## Evaluation boundary

The four context conditions and six Procurement tasks are fixed and machine-readable. Scoring is deterministic and replayable. The included replay is a synthetic scorer test, not a recorded language-model result. A provider can implement the exported driver interface, but credentials, prompts, sampling, repetitions, and analysis remain outside the compiler and health suite.

## Deferred work

Complete task/effect/reversibility/recovery closure is the principal semantic gap. Real comparative LLM experiments, benchmark publication, generated or attested extensions, and complete SML-Agent conformance remain separate future work.
