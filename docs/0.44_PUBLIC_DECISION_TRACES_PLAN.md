# ModelLang 0.44 bounded public decision traces

## Outcome

ModelLang 0.44 adds an authenticated, input-specific explanation of current action applicability over HTTP and MCP. It reuses the authoritative evaluator and publishes only ordered categorical authorization, requirement, and revision outcomes plus the existing safe applicability decision.

This is deliberately not a public copy of private `action_audit.decision_evidence`. It contains no action input, evaluated state value, authenticated identity, expression, policy or authority identity, or private evidence; it observes no execution and writes no audit row.

## Threat model

Trace consumers may use the result to understand why one exact action is or is not currently applicable. They must not cache it, infer authority from it, or treat it as proof of execution. Every response declares point-in-time freshness, zero reusable lifetime, revalidation before reuse, no-store transport, `authority: "none"`, and incomplete trace closure. Later action execution authenticates and re-enforces every current rule.

The trace request rejects command metadata and delegated credentials. Stable safe applicability rule IDs and categorical outcomes are public; inputs, facts, policies, branches, expressions, identities, and private durable evidence stay behind the runtime boundary.

## Runtime surfaces

Generated HTTP clients and servers expose `POST /agent/decision-traces`. Generated MCP servers expose `modellang_public_decision_trace` as a separate read-only tool whose structured content and embedded resource are the unchanged trace envelope. The MCP resource URI contains only model identity and a random trace ID.

Actions remain commands. Query-backed resources remain current-state reads. Task packets remain partial planning context. Delegated capabilities remain narrowly attenuated authority. Public traces explain only current applicability and grant no authority.
