# ModelLang 0.48 Agent Plugin packaging

## Outcome

ModelLang 0.48 makes a deployed generated application directly packageable for Agent Plugins 1.0.0 clients. A compiler caller supplies the public Streamable HTTP MCP endpoint at deployment time and receives a separate `agent-plugin/` package root containing the standard `plugin.json` and connection-only `mcp.json`.

The package locates an application. It does not grant authority. Client-managed authentication and the existing ModelLang request authentication, authorization, row policy, disclosure, freshness, delegation, and extension enforcement remain mandatory.

## Contract

- opt-in CLI flags: `--agent-plugin-url <url>` and optional `--agent-plugin-name <name>` on `modelc build`;
- package root: `<build-output>/agent-plugin/`;
- pinned external package format: Agent Plugins 1.0.0 Working Draft;
- component: one remote `streamable-http` MCP server entry;
- default package and server name: `modellang.<normalized-model-name>`;
- package version: the source model version;
- URL safety: absolute HTTP(S), no user information, no fragment, and HTTPS outside loopback;
- credentials and literal authentication headers: never generated; the caller-supplied URL is visible package data and must contain no secret;
- schemas: canonical Agent Plugins identifiers in output plus pinned local schema copies for deterministic conformance tests;
- provenance: both package documents are deployment contracts when packaging is requested.

## Boundary

The source model and canonical IR do not contain a deployment URL or Agent Plugins metadata. Ordinary generation remains deterministic from IR alone and emits no plugin package. The ModelLang model-root `mcp.json` remains adapter manifest v6; the Agent Plugins connection document is isolated at `agent-plugin/mcp.json`, where that standard requires it.

The generator does not emit Agent Skills, client-specific extensions, stdio launchers, SSE fallback, credentials, archives, registry metadata, installation state, update policy, or a claim that any particular client successfully connected. Distribution and client enablement remain host concerns.

## Version axes

- compiler and examples: 0.48.0;
- generator: `postgresql-http-ui-agent-plugin/32`;
- Agent Plugins package format: 1.0.0 Working Draft;
- canonical IR1, MCP adapter v6, catalog v7, target profile v9 and target `/9`, assessment/evaluation formats, and runtime envelope versions: unchanged.
