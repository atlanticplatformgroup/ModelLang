# Whitepaper

[`THE_SEMANTIC_MODEL_LAYER.md`](./THE_SEMANTIC_MODEL_LAYER.md) is the repository-owned edition of Nick Scipione's 2026 whitepaper. It is revised alongside ModelLang releases; the current implementation-status claims describe ModelLang 0.50 and remain versioned with the compiler they describe.

The paper remains an architectural and research proposal. The implementation matrix near its beginning and the conformance declaration in Appendix B distinguish demonstrated ModelLang behavior from partial and research-stage capabilities.
